# App assets

- `ambient.wav` — original quiet ambient soundtrack used by the game.
- `pixelchess-icon.png` / `pixelchess-icon.svg` — application icon.
- `presplash.jpg` / `presplash.svg` — Android launch screen artwork.
- `github-mark.svg` / `github-mark.png` — GitHub mark for the About button in the light theme.
- `github-mark-light.svg` / `github-mark-light.png` — GitHub mark for the About button in the dark theme.
- `pieces/` — six white and six black chess pieces in PNG format, with matching editable SVG originals.
